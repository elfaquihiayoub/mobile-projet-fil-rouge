### B. POO

Create/use a simple `Rayon` class.

The class must demonstrate:

* properties
* constructor
* encapsulation
* getters
* setters where necessary
* object creation

Example concept:

```php
class Rayon
{
    private $id;
    private $nom;

    public function __construct($nom, $id = null)
    {
        $this->id = $id;
        $this->nom = $nom;
    }

    public function getId()
    {
        return $this->id;
    }

    public function getNom()
    {
        return $this->nom;
    }

    public function setNom($nom)
    {
        $this->nom = $nom;
    }
}
```

Do not blindly use this exact code if the Session 2 project uses another structure.

Follow the Session 2 implementation.
