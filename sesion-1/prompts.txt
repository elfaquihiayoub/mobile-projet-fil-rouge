# Admin Dashboard — Professional UI/UX Design Prompt

Design a **modern, professional, clean, and responsive Admin Dashboard UI** for a **library management system**.

## IMPORTANT DEVELOPMENT CONSTRAINT

The UI must be designed **strictly according to the existing system and use case provided below**.

**Do NOT:**

* Add new features that are not mentioned.
* Change the application's workflow.
* Change the business logic.
* Add user/client functionality to the admin dashboard.
* Add authentication flows, notifications, payments, reservations, or other features.
* Invent additional CRUD modules.
* Change the meaning or relationships of the existing entities.

The goal is to create the **Admin Dashboard interface for managing the existing library system**, with CRUD operations and management screens matching the use case exactly.
